Pour ouvrir les jeux interactifs

Si ce message reste affiché, l’aperçu du fichier bloque JavaScript. Il ne s’agit pas d’un cahier PDF : ce fichier est une application Web.

Sur ordinateur : télécharge le fichier HTML, ouvre le dossier Téléchargements, puis double-clique sur le fichier (ou clic droit → Ouvrir avec → Chrome / Edge / Firefox). Évite de le consulter directement dans l’aperçu d’un service de fichiers ou d’un courriel.

Pour une classe : ouvrez ce fichier téléchargé dans Chrome ou Edge, ou hébergez-le dans un environnement scolaire à accès contrôlé. Les documents ne sont pas destinés à une diffusion publique sans vérification des droits.

Si la page reste bloquée après son ouverture dans un navigateur, vérifie que JavaScript est autorisé par le navigateur ou le réseau scolaire.
